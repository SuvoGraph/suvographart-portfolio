SUBHADEEP ASH — CUSTOMISABLE PORTFOLIO STARTER

FILES
- index.html   Website structure
- styles.css   Visual design and responsive layout
- script.js    YOUR CONTENT: name, location, email, images, services, portfolio items

OPEN IN VISUAL STUDIO CODE
1. Extract the ZIP to a folder.
2. Open Visual Studio Code.
3. Choose File > Open Folder, then select this extracted folder.
4. Open script.js and edit the PROFILE object near the top.
5. Save the file and open index.html in a browser.
6. Recommended: install the "Live Server" extension in VS Code, right-click index.html, and choose "Open with Live Server".

HOW TO CHANGE PROJECT IMAGES
- Easiest: put your image files in a new folder named "images" beside index.html.
- Then set image paths like: "images/my-logo-project.jpg"
- For your portrait, set PROFILE.portrait to "images/my-portrait.jpg".
- Use your own work or images you have permission to publish. The current online images are placeholders and require internet access.

HOW TO PUBLISH AND SHARE A WEBSITE LINK
The code on your computer is not automatically online. To share it, publish the folder with a hosting service such as GitHub Pages or Netlify:
- GitHub Pages: create a repository, upload these files, then enable Pages in repository settings.
- Netlify: sign in, then deploy the project folder using its manual deploy option.
The host will provide a public URL that you can send to clients.

IMPORTANT
This is an original, editable portfolio starter inspired by the general structure of the linked Maria demo (hero/about/services/portfolio/contact), not a pixel-perfect copy of its proprietary template. The reference template is a commercial ThemeForest item; use the original purchased files if you need its exact design/assets.
The contact section opens the visitor's email app using a mailto link. It does not store messages in a database.
